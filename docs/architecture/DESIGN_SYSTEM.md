# SparkHub Design System Foundation

Status: Phase 4 foundation.

SparkHub should feel professional, energetic, and trustworthy. The visual system must support serious idea discovery without drifting into crypto, hype, or fake marketplace metrics.

## Direction

- Primary brand signal: deep forest green `#1f7a5a`.
- Supporting action and discovery color: intelligent blue `#3157a4`.
- Selective emphasis: restrained amber `#d4912a`.
- Base surface: warm neutral `#f6f3ed`.
- Core ink: `#101817`.
- Cards and controls use 8px radius unless a smaller radius is needed inside dense UI.
- Motion should feel precise and calm: short reveal, subtle lift, no distracting loops for core reading surfaces.
- Respect reduced-motion preferences.

## Product Rules Reflected In UI

- The homepage must show the sequence `Idea Poster -> Idea -> Investment Interest -> Connection -> Investment`.
- Public pages must never imply that clicking interest creates an investment.
- Role pages should be separate enough that idea poster, investor, mentor, and admin workflows can evolve independently.
- Public metrics must come from real records. Do not add invented user counts, funding totals, or traction numbers.
